# Доктор Асан Джемилев — сайт пластического хирурга

Статичный одностраничный сайт (HTML/CSS/JS, без сборки и без бэкенда).
Цветовая схема — белый и синий, стиль — экспертный, спокойный, «стерильный».

## Структура

```
index.html        — вся разметка и тексты
css/style.css      — стили (цвета, типографика, сетки)
js/script.js        — мобильное меню + обработка формы заявки
assets/favicon.svg  — иконка сайта
```

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `doctorasan-site`.
2. Загрузите в него все файлы из этой папки (сохраняя структуру `css/`, `js/`, `assets/`).
   - Через веб-интерфейс: «Add file» → «Upload files» → перетащите папку целиком.
   - Или через терминал:
     ```bash
     git init
     git add .
     git commit -m "Первая версия сайта"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/doctorasan-site.git
     git push -u origin main
     ```
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Source** выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/doctorasan-site/`

## Что стоит донастроить перед публикацией

- **Телефон и адрес клиники** — сейчас указаны данные из открытых источников (ПроДокторов), лучше уточнить актуальные у клиники и заменить в `index.html` (блок `#contact`).
- **Форма заявки** — сейчас она ничего никуда не отправляет (сайт статичный), а просто показывает пациенту просьбу продублировать заявку звонком. Чтобы форма реально отправляла заявки, подключите один из бесплатных сервисов для статичных сайтов — например, Formspree или Getform (нужно всего заменить `action` формы и добавить `fetch`-запрос в `script.js`).
- **Фото врача** — вместо иллюстративной SVG-заглушки в блоке «О враче» стоит поставить реальную фотографию доктора (замените `.about-portrait` в `index.html` на `<img>`).
- **Домен** — при желании можно подключить свой домен через файл `CNAME` в настройках Pages.

## Источники контента

Тексты подготовлены на основе информации из открытых профилей врача (ПроДокторов, «Врачи Города» и др.). Отзывы пациентов пересказаны своими словами (не дословное цитирование) — рекомендуется свериться с формулировками и заменить на реальные, согласованные с клиникой тексты перед публикацией.
